# A room is an organization's lasting place, separate from sessions and setlists

People playing together join a **room**: one link per room that never changes (an "Adult Jam" link), owned by an organization. Whatever the room's leader loads, a setlist or a lone session, everyone in it follows without reconnecting; when the room is not live, the same link opens its setlist for each person to practise. We chose this over joining a session or a setlist directly (a new link, and a reconnect, every time the leader changes what is open) and over a room made fresh for each event (a link nobody can keep), because a band should connect once at an event and keep one link from week to week. Guests may join without an account and are recognised each time. The cost of changing this later is every link already handed out.
