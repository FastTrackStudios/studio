The Project Launcher has a Share button on each setlist: it opens the app's Share sheet on the set, which shows the links the set already has (to copy, name, pause or revoke) before offering a new one. The launcher now reads sets and songs with `setlists::rows`, the model the web dashboard reads them with. In the web app a song's Chart tab shows the chart alone (a page icon; lyrics are the Lyrics tab) (session)
