A set whose song line plays an arrangement (`@Big Intro`) follows that arrangement's chart: a Keyflow chart in the song's `Arrangements/<name>/` folder, else one named like the song and the arrangement. It never falls back to the song's own chart, which has another form and often another key; with none, the chart generated from the arrangement's session shows (studio#624).
