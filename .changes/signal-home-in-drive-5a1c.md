Signal's rig files (NAM captures, IRs, sample libraries, kit and plugin presets) are found in the Signal home, `<Studio home>/Signal` (Drive's `Studio/Signal`), on every machine. A path saved before the move (`/run/media/AudioHaven/Signal/…`) reads as the same file there, so old presets and songs open unchanged. A file Drive has not brought to this computer fails with a message to pin it, not silently. The built-in defaults name their files by their place in the home (`utils::home`).
