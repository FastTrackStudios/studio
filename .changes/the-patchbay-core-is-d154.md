The Patchbay core is a linked Architect extension (patchbay::ext::Patchbay): the patchbay view and the PATCHBAY_STATUS, _HEALTH, _NOW, _DEVICE_LIST and _DEVICE_SHOW actions, over one engine per machine (patchbay::server::Engine attaches to a running engine or starts one). (studio)
