The Patchbay views draw in Blitz (Architect window): no page JavaScript in the UI (a shell-given ui::Page keeps preferences and the colour scheme), dropdowns and sliders built from divs (ui::ui::Choice, ui::ui::Slider) instead of <select>, range inputs and change events, and a native sheet for Blitz CSS gaps. (studio)
